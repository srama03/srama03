## 💫 About Me

👩🏽‍💻 Computational Data Science @ Penn State

📊 **Interests:** Applied Machine Learning, Representation Learning, Human-Centered AI, Data Science

🔧 **Recent work includes:**
- 🧠 Molecular flavour retrieval using Graph Neural Networks (GCN, GIN, RDKit, FAISS) with latent space evaluation and perceptual validation
- 🔁 Deep Equilibrium Models (DEQs) for intent classification on the Banking77 dataset using implicit differentiation and robustness evaluation
- 📈 Simulation-driven ML for semi-dynamic project delay prediction with MLflow experiment tracking and Dockerised training/inference
- 📅 CPM/PERT schedule analysis tool with an interactive Streamlit interface

🌱 **Currently exploring:**
- Graph representation learning
- Embedding evaluation and representation geometry
- Similarity search and retrieval systems
